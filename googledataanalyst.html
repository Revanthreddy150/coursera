Data Analytics Course Assignments

Module 1 - Assignment 1

Question 1

What type of data is primarily represented in the "Quantity" column?

Answer: Numerical data
Question 2

The data in the "Order Date" column is a specific type that can be used to track events over time. What type of data does this column contain?

Answer: Date data
Question 3

In the "Customer Rating" column, most of the entries are numbers from 1 to 5. However, there is one entry that is a word. This is an example of what common data issue?

Answer: Inconsistent data
Question 4

If "Order ID 1005" has a blank entry in the "Customer Rating" column, what is the most important reason a data analyst would need to address this before performing an analysis?

Answer: The blank entry is missing data that could affect calculations like an average rating.

Module 2 - Assignment 1

Question 1

There are six phases in the data life cycle, which culminate with analyze, archive, and destroy. What is the correct order of the first three phases?

Answer: Plan, capture, manage
Question 2

Fill in the blank: During the _____ phase, data teams decide what kind of data is needed and who will be responsible for it.

Answer: planning
Question 3

A data team considers how and where data will be stored, what tools are required to safeguard it, and how to maintain it properly. What phase of the data life cycle does this scenario describe?

Answer: Manage
Question 4

What is the term for the computer system in which organizations store their data?

Answer: Database
